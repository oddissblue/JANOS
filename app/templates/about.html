About the project

JANOS began as a student project at Imam Abdulrahman Bin Faisal University in Dammam, Saudi Arabia. This repository provides a reproducible environment for exploring its image classification model.

The model has no documented clinical validation in this repository. Do not use its output to make medical decisions.
