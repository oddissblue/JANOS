Using JANOS

Help and frequently asked questions

Learn what the scanner accepts and how to interpret its output.

How do I scan an image?

Create an account, sign in, and open the scanner. Choose a PNG or JPEG image up to 10 MiB, then select Run scan. Your result will also appear in your account history.

What does the score mean?

The model produces a binary score. Values above 0.5 select pneumonia; other values select normal. The displayed class score is not a calibrated likelihood of disease.

Who can access my uploaded images?

The application checks account ownership before serving an uploaded image. Administrators with access to the database or storage can still access data. Use sample or appropriately de-identified images.

Why did a scan fail?

Check the file size and format. If a valid image still fails, the model or server may be unavailable. Contact the operator; technical setup instructions are in the repository README.

How do I reset my password?

Select Forgot password on the sign-in page. Reset links expire after 30 minutes and stop working after the password changes. Email delivery must be configured by the operator.
